## 状态定义

### Inbox（收件箱）

**定义**：原始捕获，尚未加工

**条件**：
- 来源不限（Telegram / Readwise / 随手记）
- 格式不限（可能混乱、不完整）
- 标签：`inbox`

**流转规则**：
- 每日处理（通过 `process_inbox.py`）
- 超过 7 天未处理 → 提醒
- 超过 30 天未处理 → 自动归档

---

### Seedling（幼苗）

**定义**：已提取核心观点，需要发展

**条件**：
- 已通过 `atomize_note.py` 处理
- 有明确标题和核心主张
- 标签：`seedling`

**流转规则**：
- 关联到至少 1 个 Map 或 Project
- 3 个月内无更新 → 降级为 Archived

---

### Budding（发芽）

**定义**：论点已完善，开始有引用

**条件**：
- 至少 2 条出链（引用其他笔记）
- 至少 1 条入链（被其他笔记引用）
- 标签：`budding`

**流转规则**：
- 持续更新，有新的 evidence 来源
- 1 年内无更新 → 降级为 Archived

---

### Evergreen（常青）

**定义**：经过时间考验，可广泛引用

**条件**：
- 至少 5 条入链
- 6 个月内有过更新
- 不是特定项目的一次性笔记
- 标签：`evergreen`

**流转规则**：
- 定期复习（间隔重复）
- 标记为核心知识节点

---

### Archive（归档）

**定义**：不再活跃维护

**条件**：
- 状态：`archived`
- 不参与每日简报和搜索排名

**流转规则**：
- 可以重新激活（改为 seedling/budding）
- 保持原有链接关系

---

## 流转规则

| 流转 | 触发条件 | 操作 |
|------|----------|------|
| Inbox → Seedling | 原子化成功 | 添加 `seedling` 标签 |
| Seedling → Budding | 有 2+ 出链和 1+ 入链 | 改标签为 `budding` |
| Budding → Evergreen | 有 5+ 入链，6 个月内更新 | 改标签为 `evergreen` |
| Any → Archive | 超过时限无更新 | 改状态为 `archived` |
| Archive → Seedling | 被重新引用 | 重新激活 |
